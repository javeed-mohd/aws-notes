sudo su :
=========

-> Switches to root user
-> Keeps current user’s environment
-> Does NOT start a login shell
-> Keeps current directory

Example:

[ec2-user@IP_Address /app]$ sudo su
[root@IP_Address /app]#

You are root, but still in /app.


sudo su - :
===========

-> Switches to root user
-> Starts a login shell
-> Loads root’s profile files
-> Changes directory to /root

Example:

[ec2-user@IP_Address /app]$ sudo su -
[root@IP_Address ~]#

Now you are in /root.
