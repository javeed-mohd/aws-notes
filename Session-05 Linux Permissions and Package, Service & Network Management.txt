Permissions:
============

drwx- -> Directory/Folder
-rwx-- -> File


- 	rw- 		r-- 	r--
	User/owner	group	others
	u		g	o


R --> Read
W --> Write
X --> Execute

chmod o+w <file-name>  --> To add permission
chmod o-w <file-name>  --> To remove permission

either owner of the file or root user can only change access levels

R -> 4
W -> 2
X -> 1

chmod 764 <file-name> --> [764 --> 7 (All) - For Owner, 6 (Read and Write) - For group, 4 (Only read) - Others]


Ownership:
==========

chown <user-name>:<group-name> <folder-name>
Ownership can only be changed by root user, not even owner of the file can change the ownership

sudo chown -R <user-name>:<group-name> <folder-name> --> Used to change ownership inside the file also by using recursive(R)
