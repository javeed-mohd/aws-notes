2. No error handling
3. Little complex
4. Large scale servers handling is tough
5. Distribution specific, homogenous(It only works for one Linux)

Copying files from one server to other server --> Example:-  scp mongo.repo mongodb.sh ec2-user@172.31.21.100:/tmp, where scp--> source copy, mongo.repo & mongodb.sh are source files, ec2-user@private ip address of other server, /tmp --> location to store the files.

ssh ec2-user@172.31.21.100 'cd /tmp && sudo sh mongodb.sh' --> For executing the file from other server

ansible all -i Ip address of other server private, -e ansible_user=ec2-user -e ansible_password=DevOps321 -m ping --> Where m for modules, e for extra arguments

ansible all -i 172.31.21.100, -e ansible_user=ec2-user -e ansible_password=DevOps321 -m dnf -a "name=nginx state=installed" --> Where a for arguments and this output will be failed as it is not a root user

ansible all -i 172.31.21.100, -e ansible_user=ec2-user -e ansible_password=DevOps321 -b -m dnf -a "name=nginx state=installed"  --> Where b for become root user and the output will be successful

ansible all -i 172.31.21.100, -e ansible_user=ec2-user -e ansible_password=DevOps321 -b -m service -a "name=nginx state=started" --> To show output on the browser
