Variables execution sequence:
============================

1. Args
2. Task 
3. File 
4. Prompt
5. Play 
6. Inventory (If not any of these, then we will get undefined variable as output in terminal)


Modules/Tasks/Collections:
==========================

ansible.builtin.command vs ansible.builtin.shell

If we don't find any module available for your requirement, then use command module or shell module accordingly.

Command Module:
===============

--> Simple commands you can execute
--> You can't get complete shell environment of the remote server
--> More secure
> (redirection) , | (Piping) will not work here. (redirection does not show output on the terminal)

Shell Module:
=============

--> You will get the entire environment of the server
--> Less secure

> (redirection) , | (Piping) works here.

ssh ec2-user@IP 'echo "Hello" > /tmp/hello.txt'

======

item is the keyword to indicate the loop values

Ansible loops keyword is loop
