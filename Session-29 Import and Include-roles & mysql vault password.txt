import_role and include_role:
=============================

1. Tags applied to import_role will be automatically applied to all the tasks inside it.
2. Tags applied to include_role will not be cascaded. As it won't respect tags.
3. import_roles parse the playbook before execution, it is static. include_role is dynamic, it will directly execute the playbook, it will not parse like import_role before execution.
4. Conditions applied to import_role is applied to all the tasks, include_role will not care the condition applied to it.
5. You cannot use loops on 'import_role' statements. You should use 'include_role' instead.

Parallel Execution:
===================

Ansible by default connects 5 servers at a time, called as forks.

FORKS:
======
--> Forks defines how many hosts Ansible can manage in parallel during execution.
forks = 8
Each task is targeted on 8 servers
Single playbook execution


SERIAL:
======
--> Serial runs the entire playbook in batches of hosts.
serial=5
8 forks -> 5
--> Run entire playbook (Still batch wise execution)
next 3 servers

THROTTLE:
=========

Throttle limits how many hosts execute a specific task at the same time.

throttle: 2 , From 5 serials -> First 2 servers restart , run specific tasks, next 2 servers restart and so on
