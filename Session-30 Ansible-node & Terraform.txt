FIPS = Federal Information Processing Standards
FIPS standards are published by:
National Institute of Standards and Technology (NIST), USA.

When a system is in FIPS mode, it means:
=> The operating system allows ONLY government-approved cryptographic algorithms.
=> Non-approved algorithms are blocked.

FIPS mode initialized
Skipping ssh-ed25519 key

==> Your RHEL is running in FIPS mode
==> It rejected ED25519 SSH key
==> It accepts RSA keys

NORMAL MODE: Any modern secure encryption can be used.

FIPS MODE: Only officially approved encryption algorithms are allowed.


FIPS-approved alternatives:
-> RSA (2048+ bits)
-> ECDSA using NIST curves (P-256, P-384, P-521)
-> SHA-2 hashing

Blocked in FIPS mode:
-> ED25519
-> Curve25519
-> Some modern non-NIST curves

Advantages of TERRAFORM:
========================

1. Version control -> We can have history of our infra. Easy to restore. Can track who changed and review
2. Consistent infra -> DEV, UAT and PROD
3. CRUD -> inventory management
4. Cost optimisation 
5. Dependency management -> automatic in terraform
6. Reusable infra -> terraform modules
7. Time saving and no human errors
