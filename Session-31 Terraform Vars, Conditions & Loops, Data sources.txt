TERRAFORM:
==========

We need to understand what are the advantages and problems terraform is solving. It is popular infrastructure as a tool (IaC) tool as of now. 

Advantages of IaC:
==================

--> Version Control: Since it is code, we can maintain in GIT to version control it. We can maintain complete history of development. Collaboration is easy.

--> Consistent Infrastructure: Often we face the problem diff configurations in different environments like DEV, QA, PROD, etc. Using terraform we can create the infrastructure in multiple environments with more reliability.

--> Automated Infra CRUD: Using terraform we can create entire infra in minutes reducing the human errors while creating manually. Using terraform we can update the infra easily. Using terraform we can delete the infra easily.

--> Inventory Management: If we create infra manually it is very tough to maintain the inventory of services. But by seeing the terraform resources anyone can know the services being used for project.

--> Cost Optimisation: When we need infra we can create in minutes. When we don't need we can destroy in minutes. Saving cost and time.

--> Automatic dependency management: Terraform can understand the dependency between resources while creating, updating and deleting.

--> Modular Infra: We can develop our own modules or use open source modules to reuse the infra code. Any one can reuse our code and create infra instead of spending more time on their own.

INTERPOLATION:
==============

In Terraform, interpolation means inserting the value of a variable or expression into a string.

It allows you to dynamically build strings using variables, resource attributes, or functions.

Interpolation is inserting dynamic values (variables, resource attributes, functions) into strings.


Data Sources:
=============

Terraform data sources are used to query and fetch existing information from your provider (like AWS, Azure, GCP, etc.) so you can use that data in your Terraform configuration.

They let you read existing resources instead of creating new ones.

Why Use Data Sources?

You use a data source when:
-> The resource already exists (created manually or by another Terraform project)
-> You need dynamic information (like the latest AMI ID)
-> You want to reference shared infrastructure (VPCs, subnets, etc.)


Data Source vs Resource:
========================

resource = "Create this"
data	 = "Look this up for me"

Resource				Data Source
=========				============
Creates or manages infrastructure	Reads existing infrastructure
resource block				data block
Changes affect real infra		Read-only


-> Data sources are evaluated during terraform plan
-> They do not modify infrastructure
-> If the queried resource doesn't exist → Terraform will fail
-> Useful for multi-environment setups
