Conditions:
===========

expression ? "true-value" : "false-value"

1. default values inside variables.tf
2. terraform.tfvars 
3. command line (Highest)
4. env variables


Execution Order:
================

1. command line -> -var="var_name=value" (Highest preference)
2. tfvars (terraform.tfvars file)
3. env variables -> export TF_VAR_VAR_NAME="value" (TF_VAR is the syntax) (set/export)
To unset ==> unset TF_VAR_VAR_NAME
4. default values


for_each loop:
==============

set or map
each -> special variable

count, for_each, dynamic (only for repeated code inside resource)
count -> list based, index based values ( Order matched, Allows duplicate values)
for_each -> map(Key=value pairs) or set (No order guaranteed, No duplicate values)
