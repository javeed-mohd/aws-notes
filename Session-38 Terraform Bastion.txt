BASTION:
========
A bastion host is a special server that acts as a secure gateway to access resources inside a private network (like private VMs or instances).

Bastion Host → Security concept

Jump Server → Operational usage


Bastion Host:
=============
A bastion host is a security-focused server placed at the edge of a network.

Characteristics:
-> Exposed to the internet
-> Highly hardened (minimal software, strict firewall)
-> Used as single entry point

Architecture:			Internet -> Bastion Host(Public Subnet) -> Private EC2 Instances (Private Subnet)

Amazon Web Services:	Internet -> Public Subnet -> Bastion EC2 -> Private Subnet -> Application Servers

A Bastion Host is a hardened server exposed to the internet that provides secure access to internal systems, while a Jump Server is an intermediate machine used to connect to other servers. In many cloud environments, both terms are used interchangeably.


Jump Server:
============

A jump server is simply a machine you log into first before accessing another machine.

Example flow:		Admin Laptop -> Jump Server -> Database Server

It is mainly used for:
-> Administrator access
-> Network segmentation
-> Multi-hop SSH

example:
ssh user@jump-server
ssh user@private-server

Bastion Host VS Jump Server:
============================

Feature		Bastion Host									Jump Server
========	=============									============

Purpose		Hardened server exposed to the internet			Intermediate server used to access internal systems
Security	Highly secured and hardened						Usually secured but not always hardened
Location	Public subnet 									Often inside internal network
Access		Internet → Bastion(Public) → Private servers	Admin → Jump server → Target server
Usage		Security architecture concept					Operational access method
