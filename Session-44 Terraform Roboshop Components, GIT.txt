Create a new repository on the command line:
============================================

echo "# shell-practice" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/javeed-mohd/shell-practice.git
git push -u origin main


Push an existing repository from the command line:
==================================================

git remote add origin https://github.com/javeed-mohd/shell-practice.git
git branch -M main
git push -u origin main

git clone https://github.com/javeed-mohd/shell-practice.git
git pull

rm -r shell-practice/ --> If cloned multiple times to remove them and we can clone again, no data will be lost.
