Process (From HTTP to HTTPS):
=============================

1. Browser(Client) Hello.
2. Server acknowledge and sends the certificate.
3. Browser validates whether common name inside certificate and client entered website(domain) are same.
   Certificate Signing Request(CSR) = Public key signed by our private key + Identity(Company) information + Validity + Domain information
4. If same, it generates a random key and encrypt with public key.
5. Server decrypts that key with private key and send response to the client(browser).
6. If response matches, then browser confirms that it is connecting to the proper(exact) server.
7. From now onwards, every data between browser and server will be encrypted with that random key.
