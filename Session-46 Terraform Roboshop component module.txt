Terrafrom roboshop components:
==============================

==> Main issues arise in security group rules.
==> We use load balancer because earlier we know that cart would directly call catalogue since requests comes from that host only. But, when executing a project, we don't know how many hosts would call each component inside a subnet, so we use load balancer to send the request for desired component when a particular host requests.
==> Backend ALB acts as a mediator for backend services catalogue, user, cart, shipping and payment to establish connection between themselves. It also connects with frontend service.
==> Each component inside a subnet connect with each other with the help of backend application load balancer.
==> Backend ALB should accept traffic from frontend on port number 80(HTTP).
==> Frontend should accept traffic from frontend application load balancer on port number 80(HTTP).
==> We establish TLS(Transport Layer Security) near Front ALB which accepts traffic from public[0.0.0.0/0] on port number 443(HTTPS).
