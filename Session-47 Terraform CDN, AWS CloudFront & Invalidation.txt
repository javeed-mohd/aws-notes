CDN (Content Delivery Network) = AWS CloudFront:
================================================

==> A CDN (Content Delivery Network) in AWS is mainly provided through Amazon CloudFront. It’s a service that helps deliver your website or application content to users faster and more securely by using a global network of servers.

==> A CDN stores cached copies of your content (like images, videos, HTML files) in multiple locations around the world. When a user requests your site, the content is served from the nearest server, reducing delay.

Key Features:
=============

==> Global Edge Locations: 400+ locations worldwide
==> Low latency delivery (faster loading websites)
==> SSL/TLS encryption for secure content delivery
==> Integration with AWS services


How CloudFront Works:
=====================

You store your content in an origin (like):
--> Amazon S3 (static files)
--> Amazon EC2 (dynamic apps)
--> Elastic Load Balancing
--> CloudFront caches content at edge locations.

When a user requests data:
--> If cached → served instantly
--> If not → fetched from origin, cached, then delivered

Benefits:
=========

==> Faster content delivery
==> Reduced load on origin servers (cost saving)
==> Improved security
==> Better user experience globally

Example Use Case:
=================

==> Hosting a website:
--> Store images/videos in S3
--> Use CloudFront to deliver them worldwide

==> Streaming video content
==> APIs acceleration


Invalidation:
=============

When new deployment/release happens usually we should invalidate all the caching content, it deletes the data from all the edge servers. Content will be downloaded again from origin to edge locations.
