Helm Charts:
============

1. package manager for k8s
2. templatise manifest files

1. build image -> nginx, nodejs, jre, etc. (Dockerfile)
2. run image -> what are the resources and configs

Chart.yaml -> Chart information. name, api version, version, app version, description, etc -> metadata about the chart
templates/ -> Manifest files with placeholders
values.yaml -> Placeholder actual values here
values-dev.yaml, values-prod.yaml -> Environment specific values


helm upgrade --install <chart-name> --set key=value .		[Command Line Interface]
helm upgrade --install <chart-name> .
helm uninstall <chart-name>
helm history <chart-name>
helm rollback <chart-name>
helm rollback <chart-name> <revision>

Service account:
================

1. Create sa
2. Create IAM role and attach permission
3. Run pod with service account

OIDC provider (Open ID Connect) --  This is created for authentication protocol between two systems like third-party applications connecting securely without sharing their password.

In Amazon EKS, OpenID Connect (OIDC) is primarily used for two critical purposes: Workload Identity (IRSA) and User Authentication. 

eks OIDC (search) - First one
One time creation done by administrators.

First we have to create this, then give permission and create service account
--> eksctl utils associate-iam-oidc-provider --cluster <cluster-name> --approve
==> eksctl utils associate-iam-oidc-provider --cluster roboshop --approve


permission providing: (search eks service account create)

Syntax:
~~~~~~

eksctl create iamserviceaccount \
  --name my-iam-service-account \
  --namespace default \
  --cluster <your-cluster-name> \
  --attach-policy-arn <policy-arn> \
  --approve


As we require permission to read the secret, we have to create policy to attach to role of service account.

==> Create Policy - Secrets Manager (Service) - Read (Get Secret value) - Add arn specific (Secrets manager variable arn) - RoboshopMySQLSecretReader(Policy name) --> Policy created

Copy policy arn --> arn:aws:iam::996669628469:policy/RoboshopMySQLSecretReader



==>
eksctl create iamserviceaccount \
  --name roboshop-secret-reader \
  --namespace roboshop \
  --cluster roboshop \
  --attach-policy-arn arn:aws:iam::996669628469:policy/RoboshopMySQLSecretReader \
  --approve
