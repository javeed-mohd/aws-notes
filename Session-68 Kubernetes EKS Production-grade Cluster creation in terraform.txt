Why ingress api?
ingress api is frozen
1. No new features, No innovations
2. Only bug fixes and Security patches

python-2.X ( Only bug fixes and Security patches) vs python-3.X

ingress API does not have role separation between developer and devops admin.

To overcome role separation, Kubernetes have created new API called gateway. But controller is same. aws-load-balancer-controller
Major advantage using gateway API is role separation.

NLB is also there, which is used for networking.
ALB is used for applications.


In gateway API, resources are divided.
--> gatewayclass -> Which LB to use ALB/NLB
--> loadbalancerconfiguration -> internal/public

  -f https://raw.githubusercontent.com/kubernetes-sigs/aws-load-balancer-controller/refs/heads/main/config/crd/gateway/gateway-crds.yaml

Install AWS Load Balancer Controller:
=====================================

The Gateway API requires the ALBGatewayAPI and NLBGatewayAPI feature gates to be enabled. We also pass the VPC ID so the controller can discover the VPC correctly.

VPC_ID=$(aws ssm get-parameter --name /roboshop/dev/vpc_id \
  --region us-east-1 --query Parameter.Value --output text)

Create LoadBalancerConfiguration:
=================================

ALB-level settings — scheme (internet-facing vs internal) and IP type. In LBC v3.x, annotations on the Gateway are ignored, so all ALB settings must go here.

--> kubectl apply -f loadbalancerconfiguration.yaml
