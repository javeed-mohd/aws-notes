CI (Continuous Integration):
==========================

--> Image/AMI build
--> Infra creation
--> Commands to deploy k8 applications

--> Application is an artifact
--> Build the application
--> Test the application
--> Scan the code
--> Deploy the application

3 months sprint - Once everyone says development completed, then they go for deployment in DEV.

CI means developers regularly merge their code into a shared project—and each change is automatically tested.

Useful for:
--> Finding bugs early
--> Prevents integration problems
--> Saves time

shift-left:
===========

Instead of testing and scanning the application, after deployment can introduce lot of issues, fixing them takes more cycles again and again. But, we can shift this before deployment.

functional defects	-> Functionality is not working as expected
build errors		-> You can't build image/AMI
deployment errors	-> You can't deploy applications
configuration errors	-> You cannot configure

******** CI:
--> It is a process of integrating code into artifact. We can trigger this CI after every commit into git. We can also follow shift-left, we can do testing and scanning the code before build.

==> Shift Left means doing testing and quality checks earlier in the development process instead of waiting until the end.

Useful for:
--> Bugs are cheaper to fix early
--> Better software quality
--> Faster delivery

Declarative Vs Scripted pipeline:
=================================

Scripted pipeline	-> Old pipeline, groovy syntax. Before pipeline execution, it can't check for errors. At run time if error comes it will exit. We have more control to write scripts. Starts with node.
Declarative pipeline	-> Latest pipeline from jenkins 2.0. It allows groovy syntax, but before execution it check for errors.

We use a hybrid approach, we have script block in our declarative pipeline to have more control on the stages. (Mixing both the pipelines for better usage)

script:
-------
The script step takes a block of Scripted Pipeline and executes that in the Declarative Pipeline.
