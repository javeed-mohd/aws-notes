Multibranch Pipeline --> It can let the developers work with their own branches. Developers may be creating lot of branches for their requirements. So, you can create pipeline for each branch using multibranch pipeline.


*******
We have used multibranch pipeline in our project we created, developers whenever they want to add new feature then they will create new branch and then jenkins will automatically create pipeline for them.


Developers should choose auto-trigger, obviously he has to give his project and component name properly. If provided wrong then it is developers mistake.
